# Okara Live Attendance Dashboard — V28 Clean

A clean GitHub Pages dashboard for live SIS attendance.

## Dashboard behavior
- No Excel upload option.
- No Top Attendance filter.
- No Lowest Attendance filter.
- Includes **Zero Progress Schools**.
- Reads only `data.json` generated by GitHub Actions.
- **Update Live Data** opens the GitHub Actions workflow for a fresh SIS collection.
- **Refresh Dashboard** reloads the latest `data.json`.
- Shows COMPLETE / INCOMPLETE / PENDING data status.
- Failed schools are not silently converted into fake zero-attendance records.

## New repository
Create a new repository named:

`Okara-Live-Attendance`

Put the files in this package at repository root, including `.github/workflows/update-attendance.yml`.

## First run
1. Push/replace the files in the new repository.
2. Open **Actions → Update Okara Attendance V28**.
3. Click **Run workflow**.
4. Wait for the collector to finish and commit `data.json`.
5. Enable GitHub Pages from the repository's `Settings → Pages` using the `main` branch and `/ (root)`.

After the first successful run, the dashboard will show the latest SIS data. The dashboard's **Update Live Data** button opens the same workflow page for another manual update.

> If the repository uses a different name or owner, change `GITHUB_ACTION_URL` near the top of `index.html` to that repository's workflow URL.
